Commands
========

.. _accelerate.commands:

Accelerate provides a set of commands that can be used to manage and configure the training process. These commands can be accessed by running ``accelerate`` in the terminal.

.. contents:: Table of Contents
    :local:
    :depth: 1

.. _accelerate.commands.config:

Config
------
